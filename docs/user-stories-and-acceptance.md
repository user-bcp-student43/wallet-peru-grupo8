## Criterio de demo completa

Seguir el README y reproducir el onboarding, el pago exitoso, un reintento
duplicado y el fallo acordado. La evidencia incluye instrucciones, casos
cubiertos, simulaciones y límites en el README; salida real de las pruebas y
pasos o capturas de los escenarios, según [Hallazgos.md](./HU/Hallazgos.md).
